# PIN Keypad PWA

A simple, secure PIN Keypad application structured as a Progressive Web App (PWA).

## Files Included:
- `index.html`: The main user interface and logic.
- `manifest.json`: Web App Manifest for PWA Builder / installation.
- `sw.js`: Service Worker for offline capabilities and caching.
- `icon-192.png` & `icon-512.png`: App icons for mobile/desktop installation.

## Deployment for PWABuilder:
1. Upload all these files directly to a new GitHub repository.
2. Ensure you enable GitHub Pages in your repository settings (Settings -> Pages -> Deploy from a branch -> main).
3. Once the GitHub Pages link is active, copy the URL and paste it into [PWABuilder](https://www.pwabuilder.com/).
